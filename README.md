Before jumping into this repo:
1) Run 'python setup_environment.py' to download third-party libraries &
credentials.
2) It's better to put your Google gloud sdk to ~/google-cloud-sdk,
which is default SDK path defined in gae_import.py.
The SDK download page: https://cloud.google.com/sdk/docs/.
3) Install App Engine SDK to ~/google-cloud-sdk:
~/google-cloud-sdk/bin/gcloud components install app-engine-python
